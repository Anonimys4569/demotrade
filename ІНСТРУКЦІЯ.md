# DemoTrade - як зібрати і встановити (Android, iPhone, Windows, сайт)

Додаток - демо-біржа: 30 монет, старт $10,000, спот і ф'ючерси.
Свого сервера немає. Весь прогрес зберігається на самому пристрої.

## 1. Швидко подивитися на ПК

Відкрий файл `DemoTrade.html` подвійним кліком - він працює прямо в браузері.

## 2. Зібрати APK (Android), IPA (iPhone) та EXE (Windows)

Збирає GitHub безкоштовно, Mac не потрібен.

1. Зареєструйся на https://github.com (якщо ще немає акаунта).
2. Натисни **+ → New repository**, назва `demotrade`, тип **Public**
   (для публічних репозиторіїв збірка на macOS безкоштовна й без лімітів), **Create repository**.
3. На сторінці репозиторію натисни **uploading an existing file**.
4. Розпакуй `demotrade.zip`, відкрий папку `demotrade`, виділи **все всередині** (Ctrl+A)
   і перетягни у вікно браузера. Перевір, що в списку є папка `.github` - без неї збірка не запуститься.
   Якщо її не видно у Провіднику: Вигляд → Показати → Приховані елементи.
5. Натисни **Commit changes**.
6. Відкрий вкладку **Actions**. Там з'явиться збірка **Build apps** - зачекай 10-15 хвилин до зеленої галочки.
7. Відкрий цю збірку, внизу в блоці **Artifacts** завантаж:
   - `DemoTrade-Android` - всередині `DemoTrade.apk`
   - `DemoTrade-iOS` - всередині `DemoTrade.ipa`
   - `DemoTrade-Windows` - всередині `DemoTrade-Setup.exe` і `DemoTrade-Portable.exe`

### Увімкнути сайт (один раз)

На сайті є: головна сторінка з описом, кнопка «Торгувати онлайн» (веб-версія), кнопки завантаження
для Windows, Android та iPhone і покрокові інструкції встановлення.

1. У репозиторії відкрий **Settings → Pages**.
2. У полі **Source** вибери **GitHub Actions**.
3. Відкрий **Actions → Build apps → Run workflow**, щоб збірка запустилась ще раз.
4. Коли завдання `web` стане зеленим, сайт буде за адресою
   `https://ТВІЙ-ЛОГІН.github.io/demotrade/` (точна адреса показана в Settings → Pages).

Завдання `web` запускається останнім: воно чекає на збірки Android, iOS та Windows і кладе готові файли
на сайт. Якщо якась збірка впала, сайт усе одно опублікується, а кнопка цього файлу буде неактивною
з написом «Файл ще не зібрано». Поки Pages не увімкнено, завдання `web` буде червоним.

Цю адресу можна давати друзям: вони зможуть торгувати онлайн і завантажити додатки.

Щоб зібрати ще раз (наприклад, після змін у коді): Actions → Build apps → **Run workflow**.

## 3. Встановити на Android

Перекинь `DemoTrade.apk` на телефон, відкрий і дозволь встановлення з невідомих джерел.
Нові версії став **поверх** старої - прогрес залишиться.

## 4. Встановити на iPhone БЕЗ кабеля (через сайт) - найпростіше

1. Відкрий адресу свого сайту на iPhone саме в **Safari** і натисни **«Торгувати онлайн»**.
2. Додаток сам покаже інструкцію. Коротко: кнопка **«Поділитися»** → **«На початковий екран»** → **«Додати»**.
3. Запускай DemoTrade з іконки на екрані - він відкривається на весь екран, як звичайний додаток.

Переваги: не потрібні кабель, ПК, Apple ID і перевстановлення кожні 7 днів. Після першого запуску працює без інтернету.
Оновлення приходять самі: залив новий код на GitHub - і додаток оновиться при наступному відкритті з інтернетом.

Важливо:
- Торгуй у додатку з іконки, а не у вкладці Safari - у них окремі сховища.
- Якщо видалити іконку з екрана, прогрес зникне. Перед цим зроби Активи → Налаштування → Резервна копія.
- На Android так само: Chrome → меню ⋮ → «Встановити додаток».

## 4б. Встановити на iPhone через кабель (IPA, з Windows)

1. Встанови на ПК **iTunes** та **iCloud** з сайту Apple (не з Microsoft Store).
2. Встанови **Sideloadly**: https://sideloadly.io
3. Підключи iPhone кабелем, на телефоні натисни «Довіряти».
4. У Sideloadly перетягни `DemoTrade.ipa`, введи свій Apple ID і натисни **Start**.
5. На iPhone: Параметри → Основні → VPN та керування пристроєм → довіряй своєму Apple ID.
6. На iOS 16 і новіше увімкни: Параметри → Приватність і безпека → **Режим розробника**.

Безкоштовний підпис діє 7 днів. Щоб оновити - просто повтори крок 4 з тим самим Apple ID.

**Важливо:** НЕ видаляй додаток перед перевстановленням, став поверх - тоді баланс і монети збережуться.
Про всяк випадок у додатку є Активи → Налаштування → **Резервна копія**: скопіюй дані в нотатки,
і їх можна буде відновити навіть після видалення.

## 5. Встановити на ПК (Windows)

- `DemoTrade-Setup.exe` - установник: ставить програму, додає ярлик на робочий стіл і в меню «Пуск».
- `DemoTrade-Portable.exe` - запускається без встановлення (можна носити на флешці).

Програма не має платного цифрового підпису, тому Windows при першому запуску покаже синє вікно
«Windows захистив ваш ПК». Натисни **Докладніше → Виконати в будь-якому випадку**.

Прогрес на ПК зберігається в папці `%APPDATA%\DemoTrade` і не зникає після оновлення програми.
Прогрес на ПК і на телефоні окремий; перенести його можна через Активи → Налаштування → Резервна копія.

## Як це працює

- **LIVE** (зелений значок) - є інтернет, ціни та графіки реальні, з публічного API Binance.
- **СИМУЛЯЦІЯ** (жовтий значок) - інтернету немає, ціни рухаються самі від останньої відомої ціни.
- Лімітні ордери, тейк-профіт, стоп-лосс і ліквідації спрацьовують, поки додаток відкритий.
- Комісії як на справжній біржі: спот 0.1%, ф'ючерси 0.05%.

## Для розробки на ПК (необов'язково)

Потрібен Node.js 22+:

```
npm install
npm run dev
```

Код лежить у `src/`: `coins.ts` - список монет, `prices.ts` - ціни, `store.ts` - логіка біржі,
`screens/` - екрани, `styles.css` - дизайн, `icons/` - іконки монет, `landing/index.html` - головна сторінка сайту (тексти та інструкції можна правити прямо там), `electron/main.cjs` - вікно для Windows.

Запустити версію для ПК у себе: `npm run desktop`. Зібрати exe у себе: `npm run desktop:build` (результат у папці `release`).
